Валидация: регулярные выражения и условия для полей
- Обозначения слов:
- Допустимый “слово-токен”:
- Английские: [A-Za-z]{1,16}
- Русские: [А-Яа-яЁё]{1,16}
- Числа: [0-9]{1,16}
- Единая альтернатива: (?:[A-Za-z]{1,16}|[А-Яа-яЁё]{1,16}|[0-9]{1,16})
- Название (одно регулярное выражение):
- Требования:
- Минимум 2 слова.
- Без пробелов в начале/конце.
- Между словами только один пробел.
- Не может состоять только из числовых слов.
- Регулярное выражение:
- ^(?![0-9 ]+$)(?:[A-Za-z]{1,16}|[А-Яа-яЁё]{1,16}|[0-9]{1,16})(?: (?:[A-Za-z]{1,16}|[А-Яа-яЁё]{1,16}|[0-9]{1,16})){1,}$
- Подробное описание (одно регулярное выражение, динамическое, зависит от title):
- Требования:
- Минимум 1 слово.
- Не может полностью совпадать с названием (даже если вокруг пробелы).
- Шаблон генерируется в коде:
- Строим паттерн с запретом на полное совпадение: ^(?!\s*<TITLE_ESCAPED>\s*$)(?:[A-Za-z]{1,16}|[А-Яа-яЁё]{1,16}|[0-9]{1,16})(?: (?:[A-Za-z]{1,16}|[А-Яа-яЁё]{1,16}|[0-9]{1,16}))*$
- Где <TITLE_ESCAPED> — экранированный title для безопасной вставки в regex.
- Реализация валидаторов в scripts/index.js и scripts/edit.js:
- Функции:
- isValidTitle(str) → тестирует по фиксированному regex.
- isValidDescription(str, title) → строит динамический regex и тестирует.
- UI-ошибки: показывать под инпутами краткое сообщение; блокировать submit, если невалидно.
- Коммит: “feat(validation): add regex validators for title and description”.

Хранилище: LocalStorage и JSON
- Утилиты в scripts/storage.js:
- Ключ: const STORAGE_KEY = 'tasks'.
- Функции:
- saveTaskList(taskList) → localStorage.setItem(STORAGE_KEY, JSON.stringify(taskList.toJSON())).
- loadTaskList() → читает JSON, TaskList.fromJSON(...), если пусто — новый TaskList.
- Инициализация на страницах:
- index/details/edit при загрузке — читают хранилище.
- Коммит: “feat(storage): implement localStorage save/load for TaskList”.

Главная: список, добавление, фильтрация, сортировка, события
- UI элементы в index.html:
- Форма добавления: два инпута — title, description, кнопка “Добавить”.
- Фильтр: три кнопки или select: “All”, “Done”, “Undone”.
- Сортировка: select с опциями “dateDesc” и “titleAsc”.
- Список задач: контейнер для карточек.
- Логика в scripts/index.js:
- Загрузка:
- Загружаем TaskList из storage.
- Добавление:
- На submit: валидировать title и description.
- Создать Task.create({ title, description }); taskList.add(task); сохранить; очистить поля; перерисовать список.
- Рендер задач:
- На основе текущих filterState и sortState.
- Применять сортировку:
- dateDesc: taskList.sortByDateDesc().
- titleAsc: taskList.sortByTitleAsc().
- Затем применять фильтрацию:
- All: все.
- Done: filterByDone(true).
- Undone: filterByDone(false).
- В карточке:
- Чекбокс done (смена статуса без формы).
- Название (ссылка на details.html?id=...).
- Кнопка Редактировать → edit.html?id=....
- Кнопка Удалить → removeById(...), сохранить, перерассчитать фильтр и сортировку, перерисовать.
- События:
- Чекбокс: task.toggleDone(); save; re-render; — если активен фильтр “Done/Undone”, задача должна исчезнуть/появиться автоматически.
- Фильтр: изменение опции → пересчитать и перерисовать.
- Сортировка: select onchange → сразу сортировать и перерисовать.
- Коммит: “feat(index): implement add, render, filter, sort, and task actions”.
